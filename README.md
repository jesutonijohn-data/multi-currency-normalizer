# 💱 Multi-Currency Normalizer App

A lightweight data automation web application built with Python and Streamlit that ingests messy financial datasets, cleans currency anomalies, maps exchange rates, and outputs audit-ready normalized USD data.

## Features
- **Regex Text Cleaning:** Automatically strips out currency symbols and formatting commas.
- **Dynamic Exchange Rate Mapping:** Converts different transaction currencies into a unified base currency with fallback handling.
- **Interactive Web UI:** Drag-and-drop CSV uploader with instant table previews and a one-click download button.

## Tech Stack
- Python, Pandas, Streamlit
